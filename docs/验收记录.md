## v0.2 五档速度与大运／年份定位

17 项独立测试最终通过，分批执行：Engine 8、Geometry 3、Playback 3、原生 UI 3。新增检查包括：

- 通过真实 JavaScriptCore 在选定年份与精确交运时刻生成流盘种子；生辰核逐位不变，开始播放不会退回出生日期，后续尾迹与旧窗口精确重叠。
- T02 男命的真实起运时间为 1981-11-17 12:00（UTC+08），第 2 运始于 1991-11-17 12:00；检查交运前一毫秒与边界的干支切换。时间轴只提供已经开始的时段。
- 播放中从「时」切到「年」再切到「大运」，在相同终点与独立参考会话的轨迹逐位相同。生辰核固定，慢速档的临时末点来自真实积分。闰年二月与平年二月的推进时长不同，所有档位均遵守原每包两个模型单位的上限。
- 真实 Store 的连续两次定位、播放中的定位和晚到结果隔离；最后一次选择不会被旧请求覆盖，定位后暂停等待用户继续。
- 原生界面实际拖动年份滑条到 2001 年，再拖动大运滑条到第 4 运「庚辰」，图上时点精确对应 2011-11-17 12:00。继续播放并切换速度后保持同一会话，生辰四柱不变。

新界面测试最终约 17.34 秒；测试定位适配了 SwiftUI 合并辅助功能元素的实际结构。年份的可见文案及辅助功能文案已改为不带千位分组的年份。实际截图发现的旧拖动提示残留、滚动顶部状态栏叠字均已修复；追加断言验证「当前」预览精确对应已显示帧的时分秒，并再次检查了最终[时间控件截图](screenshots/time-controls.png)。

本地结果为 `build/Version02Tests.xcresult` 与 `build/Version02ControlsFinal.xcresult`；对应日志 `build/version02-test.log`、`build/version02-controls-final.log`。网页版本、原数学方程、固定公历／模型时间换算和算法 bundle 均未改变。

日志与结果包位于本地忽略目录 `build/`，未提交二进制构建产物：`final-test.log` 保存 8 项单元测试，`ui-test.log` 保存旋转与后台测试，`input-playback-test.log` 保存最终日期输入与连续播放测试。两项 UI 测试分别约 10.29 秒和 21.30 秒。
