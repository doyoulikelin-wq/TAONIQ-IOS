# 智道 iOS 演示验收

日期：2026-10-25。Xcode 26.3（17C529）；iPhone 17 Pro、iOS 26.3 Simulator。应用版本 0.1.0（1），最低 iOS 18。

## 构建与原生交互

`TAONIQ.xcodeproj` / `TAONIQ` scheme 模拟器构建成功，实际安装与启动成功。10 项独立测试分批通过：

| 分组 | 数量 | 验证内容 |
| --- | ---: | --- |
| JavaScriptCore 引擎 | 5 | 真实生辰生成、连续尾迹逐点保留、不同分包的同路径、非法输入隔离、在途取消与固定「至今」终点 |
| 三维几何 | 3 | 9,000 条原始相邻边完整保留、共同世界尺度、联合拟合保留大小比例 |
| 原生 UI | 2 | 拖拽两图共同视角、日期推进、暂停晚到帧不落图、续播、原生生辰修改；自动旋转但日期不变、后台暂停 |

生辰输入测试实际打开系统日期选择器，把 1975-08-27 改为 1975-08-28，并选择女命排运，再生成。主页出生起点精确增加一个公历日，排运设置与显示同步更新。界面测试运行实际算法，没有替换成轨迹图片或假响应。

自动旋转测试保留旋转开启，确认相机角度随墙钟时间改变、两图角度相同，流盘日期保持不变。演化测试暂停后等待在途计算完成，确认日期没有继续跳动；继续播放再沿同一会话推进。

日志与结果包位于本地忽略目录 `build/`，未提交二进制构建产物：`final-test.log` 保存 8 项单元测试，`ui-test.log` 保存旋转与后台测试，`input-playback-test.log` 保存最终日期输入与连续播放测试。两项 UI 测试分别约 10.29 秒和 21.30 秒。
